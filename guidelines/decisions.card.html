Tokens & Fuentes

  • Self-host fonts WOFF2 en public/fonts/ — no Google Fonts
  • Framer Motion en OptimizedHeader, OptimizedFooter, HeroAnimated, SocialCarousel — gateado por prefers-reduced-motion
  • Leaflet solo si bundle <50kb gz; sino mapa estático SVG/WebP (CoverageMap)
  • AddressAutocomplete con datasource local (barrios MDQ) — NO Google Places API
  • TypeScript estricto — .d.ts completos para todo
  • AZUL MÁXIMO = #0950F6 — todo brand-blue-700 actual → brand-blue-500 (mismo hex, token único)
  • NO font-bold en Anton/Bebas — weight 400 forzado en componentes
  • Piso 12px — eliminar text-[10px], text-[11px], text-2xs, text-xs en texto legible
  • Heroes solo azul-500 o amarillo-500 — nunca degradados, nunca azul-700/900
  • DropOFF -20% solo E-commerce 24HS — ver promises.ts línea 97

Reglas No Negociables

  • 3 colores: #0950F6, #FFEC01, #FFFFFF + semánticos
  • Anton/Bebas 400 only — NO font-bold
  • Outfit body, Geist Mono tabular-nums
  • Double bezel (--radius-card / --radius-card-inner)
  • Heroes solo azul-500 o amarillo-500
  • Touch targets ≥44px (--control-sm/md/lg, --tap-min)
  • prefers-reduced-motion apaga loops/animaciones
  • Componibilidad: solo tokens + primitivas existentes (Button, BezelCard, Badge, Input, FeatureCard, PageHero, Section, Display, Lead, etc.)
  • NO valores hardcodeados (hex, px, rem) fuera de tokens
  • Contraste WCAG AA: texto azul-500/blanco 6.02:1, azul-500/amarillo 4.94:1
